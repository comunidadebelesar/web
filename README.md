# Belesar organízase

Web pública da Comunidade Educativa de Belesar.

## Publicación en GitHub Pages

O repositorio está preparado como sitio estático. En GitHub:

1. Abrir **Settings > Pages**.
2. En **Build and deployment**, seleccionar **Deploy from a branch**.
3. Escoller a rama `main` e o cartafol `/ (root)`.
4. Gardar.

A web publicarase en `https://comunidadebelesar.github.io/web/`.

## Privacidade

Non incluír nos ficheiros públicos enderezos de correo utilizados para administrar GitHub. Configurar os commits cun enderezo privado `noreply`.
